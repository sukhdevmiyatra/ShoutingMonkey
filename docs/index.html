THE ESSENTIALS

See the crawl, then decide what to fix.

Crawl the right scope

Follow internal links, sitemaps, canonicals, hreflang, redirects, and meta refreshes. Tune depth, speed, URL limits, robots.txt handling, include rules, and user agent.

Work from evidence

Review response codes, metadata, indexability, duplicate content, images, internal linking, security headers, and structured data. Drill into inlinks, outlinks, headers, resources, and source.

Handle JavaScript sites

Use installed Edge or Chrome to render client-side pages when needed. Compare rendered output with the initial HTML crawl.

Keep a record

Crawls are stored locally in SQLite. Compare runs to find issue changes, reopen previous work, or export results as CSV, XML, and reports.

DESKTOP WORKFLOW

Built for the way technical audits are done.

Start with a URL, inspect the site structure, filter the result set, and trace each issue back to its source. Use the inspector to understand one URL before changing the site.

  • Issue lists grouped by severity and priority
  • URL details, inlinks, outlinks, headers, and source in one place
  • Saved crawls and crawl-to-crawl comparison
  • Exports for redirects, broken links, image alt text, sitemaps, and more

COMMAND LINE AND CI

Use the same crawler in a build.

The CLI can crawl a staging URL, write a JSON report, and fail a build when it finds issues at the chosen severity.

shoutingmonkey-cli crawl https://staging.example.com ^
  --report seo-issues.json --fail-on error

POSITIONING

An open-source desktop alternative for core technical SEO work.

ShoutingMonkey focuses on the core crawl and audit workflow. It is smaller in scope than established commercial suites, and it is a practical option when you need a free Windows crawler with source code you can inspect.
