FREE AND OPEN-SOURCE · WINDOWS

A desktop SEO spider for finding what needs fixing.

ShoutingMonkey crawls a website, groups the technical issues, and keeps the affected URLs, links, and page data close at hand. It is written in Rust and runs locally on Windows.

IN THE CRAWLER

Data you need for technical decisions.

ShoutingMonkey focuses on the data gathered during a crawl and the paths back to the page or link behind it.

Site and indexing

  • Internal and external links
  • Response codes and redirect chains
  • Robots.txt, directives, canonicals, and hreflang
  • XML sitemaps and orphan URLs

On-page and content

  • Titles, meta descriptions, H1s, and H2s
  • Exact and near-duplicate content
  • Image alt text, sizes, and broken images
  • Structured data, language, and viewport

Investigation and output

  • Inlinks, outlinks, source, headers, and resources
  • Saved local crawls in SQLite
  • Crawl Compare and site structure views
  • CSV, report, sitemap, and HTML exports

COMMAND LINE

Use the crawler in a release check.

The CLI uses the same crawler as the desktop application. Crawl a staging URL, save a report, and fail the command at a chosen severity.

shoutingmonkey-cli crawl https://staging.example.com ^
  --report seo-issues.json --fail-on error

FAQ

Before you download.

Is ShoutingMonkey a free Screaming Frog alternative?

It is a free, open-source desktop crawler for core technical SEO audits on Windows. It is independent and not affiliated with Screaming Frog.

Can it render JavaScript?

Yes. When rendering is enabled, ShoutingMonkey uses Microsoft Edge or Google Chrome installed on the computer.

Can I use it in CI?

Yes. The release includes shoutingmonkey-cli.exe, which can write reports and exit with a failure code for a selected issue severity.
